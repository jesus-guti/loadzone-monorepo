# Staff Wellness views and CSV per Questionnaire Version

Labels: `wayfinder:grilling`  
Status: open  
Blocked by: none

## Question

Staff Wellness lists, cards, and CSV must not mix **Questionnaire Versions**. The control is a Version switcher. CSV may include several Versions only as separate files or sheets.

Specify the staff-facing rules: what the switcher selects (Version, not date range), how empty/gap cells work when a Version omitted a WellnessMetric, how tarjetas/tablas stay flexible, and the export shape (filenames, one sheet vs many files). Warning copy when publishing a new Version belongs here only as product rules, not builder UI.
