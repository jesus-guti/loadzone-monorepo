# Carga CSV is the microcycle sheet

Staff export **Carga** so they can take the opinionated microcycle sheet into Excel and keep calculating on their own. The file is that sheet’s values for the active team and season, not a second model and not a clone of any legacy workbook. A sample “CONTROL CARGA” file round-tripped through Excel XML on Windows; where it disagrees with the sheet (a microcycle sum missing a day, 80 minutes filled on days with no session, player zeros invented for rest days), the sheet wins.

The dialect is the one in [ADR 0002](0002-team-wellness-csv-excel-es.md): UTF-8 with BOM, `;`, RFC-style quoting, comma decimals. One wide grid, one column per civil day from the Monday of the week that contains the season start through the Sunday of the week that contains the season end. Rows, in order: `Jugador` with `Microciclo N` only in that week’s Monday cell; an ISO date (`2026-08-03`) and nothing else in the day header (no weekday, no “3 ago”, no **Match Day** label); one row per active **Player**, full name, A–Z, cell = reported RPE or empty; `Tiempo` (**Team day minutes**, bare number, 0 when there is no session); `Carga del día`, `Aguda 7d`, and `Crónica 28d` as the integers the sheet shows; `A:C` to two decimals (0 when chronic is 0); `Sumatorio` only in the Monday cell. Week-scoped labels stay in a single cell so a column sum does not multiply them by seven. No chart row, no session-objective row, no “+15%” inside a numeric cell. Archived players are absent, same as the sheet, so their RPE is not in the team rows.

**Considered options:** A literal clone of the legacy workbook — preserves a broken file. Live Excel formulas — the file would stop being our calculation as soon as someone edited a cell. A long player-day table — better for pivots, a second opinion next to the sheet. Screen date labels and **Match Day** — readable, but Excel cannot treat “3 ago” as a date. Shirt number or internal id — neither is how the sheet names a player. Recomputing team rows with archived players, or listing them while leaving team rows unchanged — the file would either leave the sheet or not foot.

**Consequences:** Tests should lock this grid (BOM, `;`, Monday-only microcycle label and sumatorio, empty RPE vs 0, integers vs `A:C` scale). Do not add a second Carga download until a real consumer needs a different shape.
